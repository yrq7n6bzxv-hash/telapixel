# TelaPixel website

Public website, privacy policy and support for TelaPixel, an iPhone and iPad pixel-art app.

This repository contains website files and promotional assets only. It does not contain the Swift app source, signing certificates, credentials, or users’ artwork.

GitHub Pages publishes the `main` branch root. Preview locally with `python3 -m http.server 8080`.

Screenshots and the demonstration are actual app captures using built-in starter artwork. The app icon is the app’s own asset. No analytics scripts, external fonts or tracking pixels are included.
